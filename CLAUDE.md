# herdr-orch

An unattended agent Orchestrator built on herdr. See `CONTEXT.md` for the domain glossary and
`docs/adr/` for architectural decisions.

## Agent skills

### Issue tracker

GitHub Issues on `jesus-mata/herdr-orch`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
